Tech Stack

Frontend

  • Next.js 15+ (App Router)
  • React 19+
  • TypeScript
  • Tailwind CSS
  • Radix UI
  • Zustand (State)
  • Lucide and Hugeicons React

API Layer

  • tRPC
  • Zod
  • TanStack Query

Backend

  • Next.js API Routes
  • Node.js
  • Octokit (GitHub)
  • Amazon Bedrock Reasoning Models
  • Vercel AI Gateway
  • Website Audit API

Security

  • Web Crypto API
  • Client-side Encryption
  • Secure LocalStorage
